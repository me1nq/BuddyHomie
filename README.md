# BUDDY HOMIE: แอปพลิเคชันบริหารจัดการหอพัก

## ภาพรวมของโปรเจกต์ (Project Overview)
Buddy Homie คือแอปพลิเคชันบนสมาร์ทโฟนที่พัฒนาขึ้นเพื่อปรับเปลี่ยนการบริหารจัดการหอพักให้เข้าสู่รูปแบบดิจิทัล ปัจจุบันธุรกิจหอพักขนาดเล็กถึงขนาดกลางในประเทศไทยส่วนใหญ่ยังคงใช้ระบบแบบแมนนวล เช่น การจดค่าเช่า คำนวณค่าไฟฟ้าและค่าน้ำด้วยมือ การแจ้งซ่อมผ่านโทรศัพท์ และการติดประกาศหน้าหอพัก ซึ่งมักก่อให้เกิดปัญหาความผิดพลาดในการคำนวณ การจัดเก็บข้อมูลที่ไม่เป็นระบบ และการสื่อสารที่ไม่มีประสิทธิภาพ

แอปพลิเคชัน Buddy Homie จึงถูกสร้างขึ้นเพื่อแก้ไขปัญหาเหล่านี้ โดยรวบรวมฟังก์ชันสำคัญไว้ในแพลตฟอร์มเดียว เช่น การแสดงบิลค่าใช้จ่ายรายเดือน การชำระเงินผ่าน QR Code การแจ้งซ่อมพร้อมติดตามสถานะแบบ Real-time และระบบข่าวสารภายในหอพัก เพื่อเพิ่มความสะดวกและประสิทธิภาพในการจัดการหอพัก

## วัตถุประสงค์ (Objectives)
* เพื่อออกแบบและพัฒนาแอปพลิเคชันบริหารจัดการหอพักบนระบบปฏิบัติการ Android
* เพื่อสร้างแอปพลิเคชันที่สามารถใช้งานได้จริงในหอพักขนาดเล็กถึงขนาดกลาง
* เพื่อศึกษาการทำงานของ Flutter และ Supabase ในการพัฒนาแอปพลิเคชัน
* เพื่อพัฒนาระบบยืนยันตัวตนและการจัดการสิทธิ์ผู้ใช้แบบ Role-based Access Control
* เพื่อยกระดับแอปพลิเคชันบริหารจัดการหอพักในปัจจุบัน.

## เทคโนโลยีที่ใช้ (Tech Stack)
* **Frontend:** Flutter
* **Backend & Database:** Supabase
* **Design:** Figma

## บทบาทและสิทธิ์การใช้งาน (System Roles & Permissions)
ระบบถูกออกแบบให้แบ่งสิทธิ์ผู้ใช้งานออกเป็น 2 ระดับหลัก เพื่อความปลอดภัยและขอบเขตการเข้าถึงข้อมูลที่เหมาะสม:
1. **ผู้เช่า (Tenant):** สามารถเข้าถึงข้อมูลบิลค่าใช้จ่ายส่วนตัว การแจ้งซ่อม และรับทราบข่าวสารจากหอพัก
2. **ผู้ดูแลระบบ (Administrator):** สามารถจัดการระบบโดยรวมของหอพัก การออกบิลค่าใช้จ่าย จัดการข่าวสาร และอัปเดตสถานะการแจ้งซ่อม

## คุณสมบัติการทำงาน (Features)

### ส่วนของผู้เช่า (Tenant Features)
* **หน้าหลัก / ข่าวสาร (Home / Announcements):** แสดงประกาศสำคัญและข่าวสารจากหอพักแบบ Real-time
* **ระบบบิลค่าใช้จ่าย (Billing System):** 
  * แสดงยอดบิลรายเดือน (ค่าเช่า ค่าไฟฟ้า ค่าน้ำ และยอดรวมทั้งหมด)
  * สร้าง QR Code (PromptPay) เพื่อความสะดวกในการชำระเงิน
  * ติดตามสถานะการชำระเงินและดูประวัติการชำระเงินย้อนหลัง
* **ระบบแจ้งซ่อม (Maintenance Request):** 
  * แจ้งปัญหาอุปกรณ์ชำรุดหรือปัญหาภายในห้องพัก
  * สามารถกรอกรายละเอียดเพิ่มเติมและแนบรูปภาพประกอบได้
  * ติดตามสถานะการซ่อมได้แบบ Real-time (รอดำเนินการ / ซ่อมสำเร็จแล้ว)
* **แชทบอทผู้ช่วย (Assistant Chatbot):** 
  * ผู้ช่วยตอบคำถามเบื้องต้นอัตโนมัติ
  * ให้คำแนะนำเกี่ยวกับวิธีการชำระเงิน วิธีการแจ้งซ่อม และช่องทางการติดต่อเจ้าหน้าที่

### ส่วนของผู้ดูแลระบบ (Admin Features)
* **หน้าแดชบอร์ด / จัดการข่าวสาร (Home Dashboard / Announcement Management):** สามารถเพิ่ม แก้ไข หรือลบประกาศข่าวสารของหอพักได้ทันที
* **จัดการการชำระเงิน (Payment Management):** ตรวจสอบสถานะการชำระเงินของแต่ละห้องพัก และกดยืนยันการชำระเงินในระบบ
* **ออกบิลค่าเช่า (Bills Management):** สร้างและส่งบิลค่าใช้จ่ายให้แต่ละห้องพัก โดยสามารถระบุค่าเช่า ค่าไฟฟ้า และค่าน้ำประปาได้โดยตรง
* **จัดการการแจ้งซ่อม (Maintenance Management):** ตรวจสอบรายการแจ้งซ่อมจากผู้เช่า ดูรายละเอียดและรูปภาพประกอบ และสามารถกดยืนยันอัปเดตสถานะเมื่อดำเนินการซ่อมแซมเสร็จสิ้น

## ผลการทดสอบระบบ (Testing & Results)

### 1. ผลการทดสอบฝั่งผู้เช่า (User Functional Testing)
* **ระบบ Login:** สามารถทำงานและเข้าสู่ระบบได้อย่างถูกต้องและปลอดภัย
* **ระบบข่าวสาร:** แสดงผลประกาศจากหอพักได้อย่างถูกต้อง และมีการอัปเดตข้อมูลแบบ Real-time
* **ระบบข้อมูลค่าเช่า:** แสดงผลยอดค่าเช่าและบิลรายเดือนได้อย่างถูกต้องตามที่ถูกเรียกเก็บ
* **ระบบแจ้งโอนเงินและแจ้งซ่อม:** ผู้ใช้งานสามารถส่งข้อมูลได้สำเร็จ และระบบสามารถบันทึกข้อมูลเข้าสู่ฐานข้อมูลได้อย่างถูกต้อง
* **ระบบ Chatbot ผู้ช่วย:** ตอบสนองการทำงานได้ดีและช่วยเพิ่มความสะดวกในการใช้งาน

### 2. ผลการทดสอบฝั่งผู้ดูแลระบบ (Admin Functional Testing)
* **ระบบ Login:** สามารถแยกสิทธิ์ผู้ใช้งานและเข้าสู่โหมด Admin ได้อย่างสมบูรณ์
* **ระบบจัดการข่าวสาร:** สามารถเพิ่ม ลบ และแก้ไขประกาศข่าวสารได้ และระบบทำงานได้อย่างถูกต้อง
* **ระบบออกบิลค่าเช่า:** สามารถสร้างและเพิ่มบิลค่าใช้จ่ายให้แต่ละห้องพักได้อย่างถูกต้อง
* **ระบบจัดการการชำระเงินและแจ้งซ่อม:** ทำงานได้อย่างถูกต้อง สามารถกดยืนยันการชำระเงิน ยืนยันการแจ้งซ่อม และระบบสามารถเปลี่ยนสถานะของแต่ละห้องพักได้จริง

## สรุปผลการดำเนินงาน (Conclusion)
แอปพลิเคชัน Buddy Homie สามารถรวบรวมบริการที่จำเป็นทั้งหมดของหอพักไว้ในที่เดียว ทั้งการรับข่าวสาร การชำระบิลผ่าน QR Code และระบบแจ้งซ่อมที่แนบรูปภาพได้ ช่วยให้ผู้เช่าทำธุรกรรมต่างๆ ได้อย่างรวดเร็ว โปร่งใส และจบในแอปเดียว 
นอกจากนี้ การนำ Chatbot เข้ามาเป็นผู้ช่วยตอบคำถามเบื้องต้น รวมถึงการรวมกระบวนการแจ้งบิลและแจ้งซ่อมให้อยู่ในแอปเดียว ยังช่วยลดภาระงานเอกสาร ลดความสับสนในการสื่อสาร และประหยัดเวลาในการบริหารจัดการหอพักได้อย่างมีประสิทธิภาพ

## แนวทางการพัฒนาในอนาคต (Future Improvements)
* **Real-time IoT Smart Metering:** เชื่อมต่อเซนเซอร์เข้ากับมิเตอร์น้ำและไฟฟ้า เพื่อดึงข้อมูลและคำนวณบิลโดยอัตโนมัติ ลดข้อผิดพลาดจากการจดบันทึกด้วยตนเอง
* **AI Predictive Maintenance:** อัปเกรดระบบ AI ให้สามารถวิเคราะห์ประวัติการแจ้งซ่อม เพื่อคาดการณ์และแจ้งเตือนการซ่อมบำรุงล่วงหน้าก่อนที่อุปกรณ์จะชำรุด
* **ฟีเจอร์เพิ่มเติม:** พัฒนาระบบแจ้งเตือนการรับพัสดุ และระบบวิเคราะห์พฤติกรรมการใช้พลังงาน
